# Processed Lunar Datasets — Lunar Landing Site Navigator & MCDM Engine

This directory contains the two relational CSV databases powering the Lunar Landing Site Navigator & Multi-Criteria Decision-Making (MCDM) Engine.

Instead of hardcoding a fixed rover travel radius during preprocessing, candidate landing areas (`landing_sites.csv`) and scientific targets (`ssis.csv`) are stored separately and linked at runtime via **3D Moon-centered Cartesian coordinates (`x_km, y_km, z_km`)**. This allows the backend and browser client to evaluate any user-selected travel distance ($R_{\max}$) in `<10 ms`.

---

## 1. `landing_sites.csv` (Candidate Landing Areas)

Generated by `build_landing_sites.py`. Each row represents an evaluated **landing area patch** (not a single pixel) that passes the hard engineering touchdown slope filter (`max_slope_deg <= 15.0°`).

### Data Sources & Coverage
* **`south_pole` (`SP_00000` – `SP_XXXXX`):** Sampled across `80°S–90°S` from NASA PGDA's `80 m/px` LOLA South Pole Stereographic DEM (`LDEM_80S_80MPP_ADJ.tiff`).
* **`global` (`GL_00000` – `GL_XXXXX`):** Sampled across `80°S–85°N` from NASA SVS's global equirectangular LOLA DEM (`ldem_16.tif`, `~1.9 km/px`).
* **Featured Landmark Patches (`ARTEMIS_*`, `FEAT_*`):** Explicit `250 m` radius touchdown zones placed beside high-priority NASA Artemis III candidate ridges and non-polar geological targets.

### Column Schema
| Column | Type / Units | Description |
| :--- | :--- | :--- |
| `site_id` | String | Primary key (`SP_*` = South Pole grid, `GL_*` = Global grid, `ARTEMIS_*`/`FEAT_*` = Featured landmarks). |
| `tier` | String | Elevation source tier (`south_pole` or `global`). |
| `lat` | Float (`deg`) | Selenographic latitude of patch center (`-90.0` to `+90.0`). |
| `lon` | Float (`deg`) | Selenographic longitude of patch center wrapped to `[-180.0, +180.0]`. |
| `x_km` | Float (`km`) | 3D Moon-centered X coordinate ($R = 1737.4\text{ km}$). |
| `y_km` | Float (`km`) | 3D Moon-centered Y coordinate ($R = 1737.4\text{ km}$). |
| `z_km` | Float (`km`) | 3D Moon-centered Z coordinate ($R = 1737.4\text{ km}$). |
| `area_radius_m` | Integer (`m`) | Radius of the evaluated touchdown dispersion zone (`250 m` polar/featured; `950 m` global). |
| `elevation_m` | Float (`m`) | Mean terrain elevation relative to the `1737.4 km` lunar reference sphere. |
| `max_slope_deg` | Float (`deg`) | Steepest pixel slope within the touchdown dispersion box (`7×7` px at South Pole; `3×3` px globally). Hard-capped at `15.0°`. |
| `mean_slope_deg` | Float (`deg`) | Average slope across the touchdown dispersion box. |
| `roughness_m` | Float (`m`) | Standard deviation of elevation ($\sigma_z$) across the surrounding mobility zone (`2 km` radius / `51×51` px at South Pole; `~5.7 km` box globally). |
| `s_safety` | Float (`[0, 1]`) | Normalized **Engineering Safety Score**: $0.60 \left(1 - \frac{\theta_{\max}}{15^\circ}\right) + 0.40 \left(1 - \text{clip}\left(\frac{\sigma_z}{\sigma_{95}}, 0, 1\right)\right)$. |
| `f_sun` | Float (`[0, 1]`) | **Ray-Tracing Output ($S_{\text{power}}$):** Fraction of time the Sun is visible above the local horizon. *(Initialized as `NaN` until populated by horizon ray-tracing.)* |
| `f_earth` | Float (`[0, 1]`) | **Ray-Tracing Output ($S_{\text{comms}}$):** Fraction of time Earth is visible for Direct-to-Earth communication. *(Initialized as `NaN` until populated by horizon ray-tracing.)* |

### Note for Horizon Ray-Tracing Pipeline
When populating `f_sun` and `f_earth`:
* Route rows where `tier == "south_pole"` to `raw_data/south_pole/LDEM_80S_80MPP_ADJ.tiff`.
* Route rows where `tier == "global"` to `raw_data/ldem_16.tif` (note: `ldem_16.tif` stores elevation in **kilometers**; multiply by `1000.0` for meters).

## 2. `ssis.csv` (Sites of Scientific Interest)

Generated by `build_ssis.py` (`1,559` total targets). Unifies polar cold traps and non-polar geological/ISRU targets onto a single normalized intrinsic value scale $V_i \in [1.0, 5.0]$.

### Data Sources & Coverage
* **Polar PSRs (`1,531` rows):** Extracted from NASA PGDA's `LPSR_80S_20MPP_ADJ_1km2.csv`. Polygon centroids are parsed from the `WKT` geometry column and projected from South Pole Stereographic meters to `(lat, lon)`.
* **Curated Non-Polar & Artemis Ridge Targets (`28` rows):** High-priority lunar skylights/lava tubes, pyroclastic ISRU deposits, young volcanic complexes, farside basins, magnetic swirls, and historic Apollo calibration benchmarks.

### Column Schema
| Column | Type / Units | Description |
| :--- | :--- | :--- |
| `ssi_id` | String | Primary key (`SSI_0000` – `SSI_1558`). |
| `name` | String | Display label (official NASA crater/PSR identifier + `#gid`, or curated landmark name). |
| `category` | String | Classification (`polar_psr`, `polar_ridge`, `lava_tube`, `isru_volcanic`, `farside_basin`, `crater_peak`, `magnetic_swirl`, `silicic_volcanism`, `young_volcanism`, `historic`). |
| `region` | String | Lunar geological province or hemisphere. |
| `lat` | Float (`deg`) | Centroid selenographic latitude (`-90.0` to `+90.0`). |
| `lon` | Float (`deg`) | Centroid selenographic longitude wrapped to `[-180.0, +180.0]`. |
| `x_km` | Float (`km`) | 3D Moon-centered X coordinate ($R = 1737.4\text{ km}$). |
| `y_km` | Float (`km`) | 3D Moon-centered Y coordinate ($R = 1737.4\text{ km}$). |
| `z_km` | Float (`km`) | 3D Moon-centered Z coordinate ($R = 1737.4\text{ km}$). |
| `area_km2` | Float ($\text{km}^2$) | Surface footprint area of the PSR polygon or geological feature. |
| `v_i` | Float (`[1, 5]`) | Unified **Intrinsic Scientific Value**. For polar PSRs: $1.0 + 4.0 \left(0.75 \min\left(1, \sqrt{A / 25}\right) + 0.25 \frac{|\text{lat}| - 80}{10}\right)$. |
| `rationale` | String | Scientific or ISRU justification shown in the UI inspector. |
| `gid` | Integer / `NaN` | Original NASA PGDA database ID (populated for polar PSRs; blank for curated targets). |
| `WKT` | String / `NaN` | Original Well-Known Text (`POLYGON`) boundary string from NASA PGDA (useful for rendering true PSR outlines in 3D). |

## 3. Runtime Spatial Linking & MCDM Scoring

### Coordinate Conversion ($R_{\text{Moon}} = 1737.4\text{ km}$)
$$x = R\cos(\text{lat})\cos(\text{lon}), \quad y = R\cos(\text{lat})\sin(\text{lon}), \quad z = R\sin(\text{lat})$$

### Dynamic Science Score ($S_{\text{science}}$) for Any Travel Radius $R_{\max}$
Given a user-selected maximum rover travel distance $R_{\max}$ (in km), query all SSIs within 3D Euclidean distance $d(x, i) \le R_{\max}$:

$$R_{\text{raw}}(x) = \sum_{d(x, i) \le R_{\max}} \frac{V_i}{1 + 0.15 \cdot d(x, i)}, \qquad S_{\text{science}}(x) = \frac{R_{\text{raw}}(x)}{\max_{y} R_{\text{raw}}(y)}$$

### Final Weighted Mission Score
$$S_{\text{total}}(x) = \frac{w_{\text{safety}} S_{\text{safety}}(x) + w_{\text{power}} f_{\text{sun}}(x) + w_{\text{comms}} f_{\text{earth}}(x) + w_{\text{science}} S_{\text{science}}(x)}{w_{\text{safety}} + w_{\text{power}} + w_{\text{comms}} + w_{\text{science}}}$$
