Backend — Lunar Landing Site Navigator & MCDM EnginePython data-processing pipeline and FastAPI service powering the Lunar Landing Site Navigator & Multi-Criteria Decision-Making (MCDM) Engine.The backend handles two core workflows:Offline Geospatial Data Pipeline: Processes raw NASA LOLA elevation rasters and Permanently Shadowed Region (PSR) catalogs into relational 3D-indexed CSV databases (landing_sites.csv and ssis.csv).Real-Time Spatial MCDM & On-Demand NASA Streaming API: Ranks tens of thousands of candidate landing areas for any user-chosen rover travel radius ($R_{\max}$) in <10 ms, and streams native 20 m/px NASA GeoTIFF tiles plus live PDS spacecraft observations on demand when a user clicks an arbitrary point on the 3D Moon.Directory StructureLunar-landing-site-nav/
├── build_ssis.py             # Generates processed_data/ssis.csv (1,531 polar PSRs + 28 curated targets)
├── build_landing_sites.py    # Generates processed_data/landing_sites.csv (South Pole + Global + Artemis patches)
├── inspect_point.py          # On-demand NASA 20 m/px /vsicurl/ streamer, PDS API query & read-through cache
├── main.py                   # FastAPI application exposing /api/rank and /api/inspect endpoints
├── requirements.txt          # Python dependencies
├── .gitignore                # Excludes raw_data/ from version control
├── raw_data/                 # (Git-ignored) Raw NASA LOLA GeoTIFFs and PSR CSVs

Teammate Ray-Tracing Integration: build_landing_sites.py initializes f_sun and f_earth as NaN. Your teammate's horizon ray-tracing script populates these two columns in processed_data/landing_sites.csv using LDEM_80S_80MPP_ADJ.tiff (tier == "south_pole") and ldem_16.tif (tier == "global").Self-Expanding Custom Cache: Any valid coordinate inspected via inspect_point.py is automatically deduplicated (150 m radius) and appended to processed_data/user_inspected_sites.csv without overwriting the baseline grid.Running the FastAPI ServerStart the local API server with hot-reload:uvicorn main:app --reload --host 0.0.0.0 --port 8000
